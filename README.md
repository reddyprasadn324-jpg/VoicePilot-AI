# VoicePilot AI

VoicePilot AI is a multilingual AI automation and commerce assistant designed for Indian businesses and consumers.

## Features

- AI Voice Calling
- WhatsApp AI Assistant
- Telugu and English Conversations
- Intelligent Customer Support
- Product Search and Comparison
- Food Ordering Integration
- Travel Search Assistance

## Swiggy MCP Integration

- Food search and budget filtering
- Delivery address selection
- Cart management
- COD and UPI payment selection
- Explicit customer approval before order placement

## Technology Stack

Python, FastAPI, SQLite, Groq AI, Meta WhatsApp API, Swiggy MCP, Exotel and Sarvam AI.

## Development Status

Currently under active development. Local Swiggy integration has been tested. Public OAuth authorization and WhatsApp-based food checkout are pending.

## Security

Customer-specific authorization and explicit purchase confirmation are core requirements.
